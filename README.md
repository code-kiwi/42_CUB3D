# Cub3D

This project was developed as part of the École 42 curriculum.

## Objective
The goal of this project is to build a 3D graphical application using raycasting,
inspired by early first-person shooter engines.

## Scope
Beyond the mandatory requirements, this project includes an extended feature set
and multiple bonus elements.

## Key features
- Raycasting-based 3D rendering
- Player movement and camera control
- Multiple levels
- Weapons system
- Enemies with basic behaviors
- User interface and menus
- Jump mechanics
- Multithreading for performance optimization

## Technical stack
- C
- MiniLibX
- Math / raycasting
- Linux
